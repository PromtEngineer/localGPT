2 · Hybrid retrieval — three channels, one pool

Each channel sees the corpus differently; RRF fusion means no channel has to be right alone. With several sources in scope the whole block repeats per source and the pools merge before reranking, so chunks compete across sources.

dense

Qwen3-Embedding-0.6B · 1024-d cosine over chunks with contextual headers. Catches paraphrase and fuzzy intent.

bm25 / fts

LanceDB native full-text. Catches exact names, IDs, rare tokens embeddings blur.

visual · late-interaction

ColModernVBERT multivector MaxSim over page images. Catches chart/table/scan pages whose text layer is weak — on FDA labels it beat every text configuration.

▼  top-30 per channel
RRF fusion · k=60 — rank-based, no score calibration needed
▼  top-25
Qwen3-Reranker-0.6B cross-encoder → final top-8 with [doc_id pN] provenance

3 · The agent — routed, budgeted, verified

Iterative retrieval costs 3–4× a single pass, so a cheap router decides per query. Everything that must hold is enforced mechanically — in tools, budgets and guards — because asking nicely in the prompt measurably fails.

4 · view_page — how the agent reads what text can't

The multimodal answer path. Images never enter the agent's context — the page goes to the vision model in a separate sub-call and only the text reading returns. The 2×3 region grid is the same one exposed interactively in the workbench evidence panel.

top-left
region grid · corners render ≈500 dpi
default (validated) stored 150-dpi page PNG + a focused question → reading with [caption quoted]. Reliable for labeled values: bars, pie slices, table cells, patent drawings — this is what took legal to 100%.
region zoom a named region is re-rasterized from the source PDF at 500 dpi — resolution that only exists in the vector source, not in an upscaled PNG.
opt-in: dense reader + locate→zoom + thinking gemma4:31b (dense beats the 3B-active MoE on series discrimination): a cheap locate pass names the smallest region → corner crop → thinking read ("halfway between the 0.6 and 0.8 tick marks"). Same-session A/B: health 80%→86.7%, recovering the epidemic-curve question; ~1.5× latency.
the honest ceiling interpolated values off dense multi-series line charts remain approximate (±0.1 band run to run) — when a value must be exact, the design prefers the underlying table via sql or states the uncertainty.
