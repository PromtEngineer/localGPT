# research_papers benchmark — methodology notes

- 15 questions built against 14 of the 25 corpus papers. Every hop was verified by rendering the actual PDF page with a visual reader (not from memory or abstracts): all table values (MTEB averages, ViDoRe/VisRAG/PopQA/QASPER/DocVQA/MIRACL/HumanEval/AIME scores) were read off the rendered tables, and both figure-read questions' charts (ColPali Fig. 3, LiM Fig. 5, DeepSeek-R1 Fig. 1) were visually inspected.
- Page numbers are ABSOLUTE PDF pages (page 1 = first page of file), located via per-page pdftotext extraction and then confirmed visually. They will not match printed page numbers where papers have unnumbered title pages.
- Cross-doc questions exploit shared entities: models appearing both in their own paper and as baselines elsewhere (ColPali/NV-Embed-v2/BGE-M3 in VisRAG or ColPali tables), shared benchmarks (MTEB 56-dataset average, PopQA, DocVQA), and comparable architecture specs (vision-encoder parameter counts).
- Caution: rp025 (DeepSeek-R1) is arXiv v2 (dated 4 Jan 2026, Nature-revision). Its layout differs from the widely-known v1: there is NO benchmark bar chart on page 1; Figure 1 (AIME-during-training + response-length panels) is on page 4 and the main comparison table (Table 8, with OpenAI-o1-1217) is on page 41 of 86. Any QA written from v1 memory would have wrong pages and wrong figure numbers.
- Caution: rp005 (CRAG) Table 1 contains two blocks (LLaMA2-hf-7b vs SelfRAG-LLaMA2-7b generators) with very different numbers for the same methods; questions must (and do) specify the generator block.
- Caution: rp022 (Qwen2-VL) mixes several metrics per row in Table 2 (e.g., AI2D shows two scores like "80.2(94.7)"); only unambiguous cells were used. rp023 DocVQA/OCRBench values come from Table 5 on absolute page 13.
- Papers avoided as unreliable/awkward for objective QA: rp008 (GraphRAG — win-rate matrices are pairwise percentages that are easy to misread), rp020 (86-page survey, taxonomy figures but few gradable numbers), rp009 (survey; TABLE I is categorical, weak for numeric QA), rp021 (ToolLLM pass/win rates vary across table variants), rp013/rp010/rp011/rp018 (fine but unused; nothing wrong found in spot checks of rp018/rp014).
- Tolerances: figure-read answers that require reading un-labeled chart lines (rp012 Fig. 5 mid-position dip, rp001 Fig. 3 Shift line, rp025 Fig. 1b response length) include explicit approximate ranges in the answer string; all other answers are exact table values.
